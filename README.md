# Rings

Playable default web build for [GameDev.Land](https://gamedev.land/games/rings).

- Play: https://gamedevland.github.io/rings/
- Platform: `web`; no Poki SDK script is loaded.
- Campaign: 100 levels, with portrait and landscape layouts.
- Source baseline: `4f4b63e4cffce790aa7bf0fba0e4769957c24c71`, including the current local campaign changes.
- Release: 2026-11-04. Game resources match the latest local Poki folder build.

This repository contains the compiled game and bundled assets, not the development project.
`build-info.json` records the source fingerprint and hashes of the generated files.
GitHub Pages publishes the root of `main`; `.nojekyll` preserves the static bundle.
