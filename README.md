# Rings 3D

Playable web build for [GameDev.Land](https://gamedev.land/games/rings).

- Play: https://gamedevland.github.io/rings/
- Source revision: `c88f456f801c511db787675d74adde6d0654a247`.
- Campaign: 100 spatial puzzles, 20 physical shapes, permanent owner-mounted lockers.
- Platform: web; no Poki SDK is loaded.

This repository contains compiled assets only. GitHub Pages publishes the root of main.
